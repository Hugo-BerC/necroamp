# Audio Engine: Design

Decisions and rationale for the protocol are in ADR 0006. This file lists modules, contracts and flow.

## Modules and dependency direction
```
src/shared/
  audio/        playback-state.ts (pure reducer), playlist.ts (ops, shuffle, repeat),
                eq.ts (bands, presets, clamp, schema), time-format.ts
  ipc/          channels.ts (+ new channels), library.ts, playlist-store.ts, settings.ts schemas
src/main/
  library/      media-registry.ts (token <-> path), metadata.ts (music-metadata), artwork.ts,
                playlist-persistence.ts
  protocol/     media-protocol.ts (pure parse + range) and media-handler.ts (fs stream)
  ipc/          library-handlers.ts, playlist-handlers.ts, settings-handlers.ts
src/preload/    adds frozen necroamp.library / playlist / settings functions
src/renderer/
  audio/        audio-engine.ts (element + graph), graph.ts, analyser-reader.ts
  stores/       player-store.ts, playlist-store.ts, eq-store.ts (Zustand, wrap shared pure code)
  features/     player, playlist, equalizer, visualizer (components read stores only)
```
`shared` stays pure (no Electron, DOM, Node). Features do not import each other's internals. The engine sits behind an `AudioEngine` interface so tests inject a fake.

## IPC contracts (all `strictObject`, `registerHandler`, bounded)
| Channel | Request | Response |
|---|---|---|
| `library:open-files` | `{ multiple: boolean }` | `{ tracks: TrackInfo[] }` (empty on cancel) |
| `library:resolve-track` | `{ trackId }` | refreshed `TrackInfo` or `{ unavailable: true }` |
| `playlist:load` | none | `{ items: TrackInfo[], schemaVersion }` |
| `playlist:save` | `{ items: PlaylistEntry[] }` (ids, max 5000) | `{ saved: true }` |
| `settings:get-audio` / `settings:set-audio` | none / `AudioSettings` | `AudioSettings` |

`TrackInfo` = `trackId`, `mediaUrl` (`media://track/<token>`), `fileName`, `title`, `artist`, `album`, `durationSec | null`, `artworkUrl | null`, `available`. No path field exists in any schema. `PlaylistEntry` identifies a track by a main-side stable id; main keeps the path mapping in the persisted file, so the renderer never sends a path. `AudioSettings` = volume, muted, eq (bands, preamp, bypass, preset), shuffle, repeat.

Because the renderer cannot send paths, `library:open-files` is the only way to add files, and dialog results are the only issuers of tokens, plus `playlist:load` for persisted entries.

## Playback state (pure)
`PlaybackState = { status, trackId, positionSec, durationSec, error }` with events `load | loaded | play | pause | stop | seek | ended | failed`. The engine emits events from element listeners (`loadedmetadata`, `timeupdate` throttled, `ended`, `error`); the store applies the reducer. Playlist logic (next, previous, shuffle order, repeat) is pure in `shared/audio/playlist.ts` and decides what to `load` after `ended`.

## Audio graph
`HTMLAudioElement(crossOrigin=anonymous)` -> `MediaElementAudioSourceNode` -> 10 `BiquadFilterNode` -> preamp `GainNode` -> master `GainNode` (volume, mute) -> `AnalyserNode` (fft 2048, smoothing 0.8) -> destination. Bypass sets biquad and preamp gains to 0 without changing stored settings. The source node is created once per element. The context resumes on the first play gesture. Dispose disconnects every node, clears `src`, and cancels animation frames.

## Visualization
`analyser-reader` exposes `getFrequencyData()` and `getWaveformData()` into preallocated typed arrays, called from one `requestAnimationFrame` loop that stops when `document.hidden` or status is not `playing`. Canvas components take plain arrays, so a skin can restyle them.

## Neutral UI and skins
Components emit commands through stores and use existing CSS variables. No audio object or file name leaks into styles. A future skin binds to the same stores and component props.

## Error handling
Element `error` or a failed metadata read yields `failed` with a fixed reason code (`UNSUPPORTED`, `CORRUPT`, `NOT_FOUND`, `DECODE`). Messages shown to the user come from the strings file, not from exceptions. Playlist auto-skips after a failure, stops after one full loop of failures.

## Persistence
Main writes `playlist.json` and `audio-settings.json` under `userData` (atomic write, Zod parse on read, `schemaVersion: 1`). Unknown or corrupt content resets to defaults.

## Alternatives
`AudioBuffer` decode (rejected: memory for FLAC, IPC bytes), AudioWorklet EQ (rejected: native biquads suffice), renderer-side tag parsing (rejected: needs file bytes in renderer).

## Risks and unverified items
CORS-enabled media over a custom scheme feeding Web Audio; decoder support per platform (FLAC/OGG on Windows, macOS, Linux); `music-metadata` ESM bundling in the main CJS output (E-ESM-1); fixtures need original or synthetic audio generated by a script with license note.
